📥 Импорт данных

Принимается msb_backup.zip (или msb_export.json / data.json без архива). Понимаются оба варианта полей: name/full_name, category/device_type, serial_number/serial, equipment_json/complectation. Идентификаторы вида c-100, r-200 и числовые id сотрудников сопоставляются автоматически; неизвестные мастера создаются как выключенные сотрудники без пароля. Повторный импорт того же файла ничего не дублирует.
